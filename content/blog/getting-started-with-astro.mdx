# Getting Started with Astro

Astro is a modern web framework that helps you build faster websites with less client-side JavaScript. In this guide, we'll explore the key features that make Astro special.

## What is Astro?

Astro is an all-in-one web framework for building fast, content-focused websites. It's designed to help you ship less JavaScript to the browser by default, which results in faster page loads and better performance.

### Key Features

1. **Island Architecture**: Only interactive components hydrate, everything else is pure HTML
2. **Zero JavaScript by Default**: Astro ships zero JavaScript unless you explicitly add it
3. **Bring Your Own Framework**: Use React, Vue, Svelte, or any other framework
4. **Content Collections**: Type-safe markdown and MDX content management

## Building Your First Site

Here's a simple example of an Astro component:

```astro
---
const greeting = "Hello, World!";
---

<div>
  <h1>{greeting}</h1>
  <p>This is rendered on the server!</p>
</div>
```

The code above the `---` markers runs on the server, while the HTML below is rendered statically.

## Why Choose Astro?

- **Performance**: Ships minimal JavaScript
- **Developer Experience**: Familiar syntax and powerful features
- **Flexibility**: Use any UI framework or none at all
- **SEO-Friendly**: Static HTML is great for search engines

## Conclusion

Astro is an excellent choice for content-focused websites like blogs, marketing sites, and documentation. Give it a try for your next project!
